AEOLIA X v0.8.0（試用版）

フォロー中・リストをコンパクトな時系列一覧で読む、Windows向けの非公式Xクライアントです。未読管理、自分のアーカイブ検索、手動取得とAPI費用の概算表示に対応します。

利用者ご自身のX開発者登録・Client ID・APIクレジット購入が必要です。API費用は利用者自身のX開発者アカウントで負担します。 X Premiumとは別です。無料で無制限にXを読める仕組みではありません。

投稿・画像・認証情報は端末内に保存し、作者へ送信する処理はありません。Xへの操作にはXへの通信が発生します。ダウンロード前に 初期設定ガイド・データの取り扱い をお読みください。

Windows x64 ／ Microsoft Edge WebView2 Runtimeが必要です。.NET 9の実行部品は同梱。ZIPをフォルダーごと展開し、Launch.exeを起動してください。未署名の試用版です。
