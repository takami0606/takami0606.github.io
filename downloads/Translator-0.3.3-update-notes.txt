# AEOLIA Local Translator 0.3.3 高品質モード

## 今回の変更
- Start-Quality.cmd / Start-Quality-API.cmd / AeoliaStart(root) はすべて、通常はタスクトレイにだけ常駐します。
- トレイのアイコンをクリックすると翻訳画面を表示・非表示にできます。右クリックメニューでも操作できます。
- 画面の×、Esc、「閉じる」は非表示にするだけです。APIは動き続けるので、既存AHKから呼び出せます。
- 完全に止める場合はトレイの「終了（翻訳APIも停止）」を選びます。
- 「モデルを休止（メモリを解放）」で手動休止できます。APIは残り、次の翻訳で自動的にモデルを再読込します。翻訳中の休止はエラーとして拒否し、翻訳を中断しません。
- 設定ファイルがない場合は自動休止しません。既存の quality-settings.json は変更せず保持します。以前60秒などを設定済みなら、その設定が優先されます。
- モデル・コアは変更なしです。同じ Qwen3-4B-Instruct-2507 Q4_K_M、4096コンテキスト、2500文字上限、既存の品質チェックを使います。0.3.2の --no-repack によるメモリ削減も維持しています。

## 更新方法
1. 軽量版を閉じ、高品質版はトレイの終了メニューでAPIも止めてください。画面の×だけでは終了しません。
2. software 0.3.3 ZIPを、既存の本体フォルダー内に展開します。
3. Update-software-0.3.3 内の Install.cmd を実行します。
4. Start-Quality.cmd または既存AHKの AeoliaStart(root) で起動します。

モデル・コアの再ダウンロードは不要です。ソフトウェアのみ更新します。旧ソフトウェアは .component-backups に残ります。会社の持ち込み・実行ルールに従い、ブロックされた場合はIT担当に確認してください。制限回避はしません。

## AHK v2からの呼び出し
既存の高品質版呼び出し方法・ポートはそのままです。

```autohotkey
#Requires AutoHotkey v2.0
#Include C:\Apps\AEOLIA\ui_quality\AeoliaLocal.ahk
AeoliaStart("C:\Apps\AEOLIA")
translated := AeoliaTranslate("Please send the document tomorrow.", "en", "ja")
; 任意。使い終わった時などにモデルのメモリを解放
; AeoliaSleep()
```

AeoliaStart(root) は起動済みなら再起動しません。画面を表示する必要はありません。
AeoliaTranslate(text, source := "auto", target := "auto", port := 51233) は同期関数です。source/target は auto / ja / en。休止中なら自動復帰します。
AeoliaSleep(port := 51233) は任意の手動休止です。翻訳中はHTTP 409になります。結果を置換する場合は、成功時だけ貼り付け、例外時は原文を残してください。会社の既存AHKマクロそのものは未検証です。

起動時はホットキー登録・クリップボード操作・Windowsログオンへの自動登録を行いません。専用GUIを表示している間だけ、従来の Ctrl+Alt+Y による選択文取得が有効です。

## 自動休止設定
本体直下の config/quality-settings.json にUTF-8で保存します。

```json
{"idle_seconds": 0}
```

0 は自動休止なし、1〜86400 は未使用秒数です。60なら60秒後に自動休止します。設定後はトレイで終了してから再起動してください。設定ファイルがなければ0です。更新でこのファイルを上書きしません。手動休止は自動休止設定に関係なく使えます。

起動直後はモデルを読み込まず、初回翻訳時に読み込みます。休止解除・初回翻訳は読み込み時間がかかります。自動休止なしの場合、翻訳後のモデルメモリは保持されます。

## 通信と制約
APIは http://127.0.0.1:51233 のみ、内部推論は51234です。ブラウザーからのアクセスは拒否します。クラウドへの自動切り替え・翻訳文ログ・プロキシ・HTTPリダイレクトはありません。高品質コアがなければエラーになり、別モデルへ自動変更しません。
数値・一部の識別子の変化や途中切れを検出しますが、意味や否定の誤りをすべて検出できるわけではありません。長い文章は分割し、翻訳結果は確認してください。

## 更新時の補足
自作AHKへヘルパー関数をコピーした場合は、更新後のui_quality\AeoliaLocal.ahkから関数も更新してください。#Include方式なら更新後のファイルを参照します。

## 確認範囲
手元PCで最終ZIPからの更新、既存コアと明示設定の保持、AHK呼出し、手動休止・自動復帰、自動休止設定、GUI表示切替・閉じた後のAPI継続・完全終了を確認しました。GUI確認は出荷処理へのテスト用呼出しとWM_CLOSEで、物理的なトレイクリック操作ではありません。会社PCのメモリ量・速度・既存マクロそのものは未検証です。
