AEOLIA Filer 0.2.2026.1114

今回の更新
・OneDrive管理フォルダーからのコピー・移動の受け入れ処理を修正。
・正常完了と通常のキャンセルでは、Filer独自の「操作結果」画面を表示しません。
・Windows標準の上書き確認、実際のエラー、安全確認による停止、完了を確認できない場合の警告は維持します。
・お気に入りフォルダーの展開状態を保存。右クリックの解凍・送る・Windowsメニューと幅調整を統合。
・アドレスバーに単一のファイルパスを貼ってEnterで関連付け起動。引用符・空白・相対パス・環境変数に対応。引数付きコマンドやシェル構文は対象外です。

導入
Windows x64 / .NET 9 Windows Desktop Runtime x64が必要です。ランタイムは同梱しません。
ZIPを全体展開し、App/AeoliaFiler.exeを起動してください。未署名ポータブル版です。
会社PCでは社内のソフトウェア利用方針に従ってください。
更新時はFilerを終了し、既存App全体をバックアップして、配布App内の5ファイルだけを上書きします。
view-settings*、お気に入り、既存データは残してください。戻す場合は終了後にバックアップを戻します。
関連付け・自動起動設定の変更は不要です。既に完了したコピー・移動はキャンセルしても元に戻りません。

検証範囲
通常版ビルドのShell/結果判定テスト57項目成功。
広範囲回帰は再実行697 PASS / 2 FAIL。既知の旧版番号固定・旧確認フロー期待の2件が残っており、全件成功ではありません。
利用者環境で前段のOneDrive→Dコピー・右ドラッグ移動は成功報告済み。
本版の通知抑制を含む実OneDrive/会社PCの再確認は未実施です。
配布は現行通常利用版と同じ5バイナリーです。設定・個人ファイル・ログ・デバッグシンボルは含みません。

従来機能の制限
検証付き移動は同名を上書きせずコピー内容を確認後、元をWindowsごみ箱を使わず削除します。
削除前の失敗は元を保持しますが、削除開始後は部分完了があり、一括巻き戻しはありません。
同期完了・復元・ACL/所有者/時刻等の保持は保証しません。
1回128ファイル・8192項目・深さ64・512MiB、パス259 UTF-16文字まで。
特殊内容や未知の再解析ポイント等は拒否します。通常Shell操作と検証付き移動では動作が異なります。
Shell拡張は通常ユーザー権限で動作し、第三者拡張すべての互換性は保証しません。
ZIPは通常の非暗号化Store/Deflateが対象。ZIP64・分割・暗号化・RAR/7z・内部ファイル実行は非対応です。
公開版確認は手動GETのみで、自動更新しません。通常の接続情報はGitHubへ伝わりますが、個人ファイルや設定を送信しません。

依存部品
配布5ファイルはAeoliaFilerアプリと自作Shellヘルパーです。NuGet第三者ライブラリーや.NETランタイムの同梱はありません。
Microsoft .NET / Windowsの実行環境にはそれぞれの利用条件が適用されます。
